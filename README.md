# AgentFlow ERP

## An Explainable Multi-Agent Enterprise Operating System with Retrieval-Augmented Intelligence

AgentFlow ERP is an AI-powered enterprise resource planning platform that combines:

- Multi-Agent AI
- Large Language Models
- Retrieval-Augmented Generation
- Explainable AI
- Human-in-the-Loop Approval
- Enterprise Workflow Automation
- Predictive Analytics

## Architecture

The system consists of:

- Next.js frontend
- Node.js + Express API
- MongoDB
- AI orchestration service
- Specialized ERP AI agents
- RAG knowledge system
- Explainable decision layer
- Human approval workflow
- Audit system
